# FUTURE_CS_01 – Vulnerability Assessment

## Future Interns – Cyber Security Internship

### Project Overview
This project focuses on identifying potential security vulnerabilities in a web application using OWASP ZAP.

### Task Details
- **Internship:** Future Interns
- **Domain:** Cyber Security
- **Task:** Task 1 – Vulnerability Assessment
- **Tool:** OWASP ZAP v2.17.0
- **Target:** OWASP Juice Shop (Localhost)

### Tools Used
1. OWASP ZAP
2. OWASP Juice Shop
3. Google Chrome
4. Windows

### Assessment Summary
- 11 alert categories identified.
- 4 Medium-risk alerts.
- 5 Low-risk alerts.
- 2 Informational alerts.
- Passive security assessment performed.

### Project Files
- Vulnerability Assessment Report – PDF
- Evidence Screenshots – Supporting assessment evidence

### Scope
The assessment was conducted on a locally hosted OWASP Juice Shop application.

### Conclusion
This task provided practical experience in web application security testing, identifying security misconfigurations, analysing alerts and documenting remediation recommendations.
